Put the code on the pixels bro
==============================

Always know where your cursor is. Its in the middle. Always. Never refocus your
eye, or look around for where you're standing, like you're having some sort of
out-of-body experience. the cursor knows where it is by not being where it
isn't.

Do games switch to tgfh when your character is sprinting? no? Consistent
movement. shift + jk move up and down by half a page. The stomped-on defaults
are remapped and still accessible. In completions, ctl + jk also move... up and
down. Shocker! ctl + l, or 'going left' accepts a selection. The tab key types
tabs.

Told Tokyo Night to eat its own jellybeans. Most code is monochrome. See
conditionals at a glance. Be alert to that glowing red return in the middle of
the function. LSP semantic tokens are not allowed any crayons. You missed a 
closing brace and know for sure its not :lsp restart time.

Leave the damn code alone. Never shift it around for editor features. Never
display things in the buffer that aren't in the file. No inline errors. No line
numbers or error column. No ghostly copilot suggestion: its an autocomple
option, right where it belongs.

Columns from 81 are subtly marked. With code at 80col, this setup comfortably
fits 2 windows side-by-side on a 16:9 display, with room to spare before text
starts to wrap.
